### Адаптивные решения в этом запуске

- Совместная активность записи и эталона обнаружена на 94.96% активных
  вокальных интервалов. Это доля доступных сопоставлений, не процент точности баланса.
- Опорная полоса 800–3500 Гц применялась там, где её поддерживали оба сигнала.
- Медиана усиления голоса — 6.392 дБ; положительный предел 8.830 дБ определён
  по оценке шума, а не выбран одинаковым для всех записей.
- Измеренный остаток ошибки относительно локального эталонного отношения:
  медиана 2.897 дБ, 90-й процентиль 11.875 дБ. Ограничение усиления затронуло
  25.66% активных интервалов. Это показывает практическую границу адаптации:
  исполнение не совпадает с эталоном по каждому 100-мс интервалу. Эти числа
  не являются оценкой субъективного качества или гарантией разборчивости.
- Динамический EQ минуса: центр около 2200 Гц, максимальное ослабление 2.989 дБ;
  вне активности исходный минус сохранялся.
- Уверенной коррекции высоты не найдено; исходная интонация сохранена.
- Достаточных оснований для дополнительных reverb/delay-посылов не найдено;
  эти эффекты не добавлялись.
