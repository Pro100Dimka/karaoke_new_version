# Видео-контент

В текущем frontend нет одного обязательного локального `.mp4/.webm`, который должен копироваться в поставку как постоянный фон.

Проект использует два типа видео:

1. **Видео песни** — задаётся песне через `video_url` или предоставляется backend как локальный clip (`local:clip`).
2. **Scene/background video** — может предоставляться Electron runtime bridge как scene media URL.

Поэтому видео в спецификации описано как runtime-контент, а не как зафиксированный статический файл.
