Cached alignment benchmark, prepared without running alignment or models.

Script: benchmark_cached_alignment.py
Harness guard tests: test_benchmark_cache.py (6 passed, no production/model import).
Guard evidence: ../benchmark-harness-selftest/result.json

Measure ONLY after current backend source and final traced payloads are frozen,
and after model processing/full test gates have finished. The script rejects a
reference trace with different backend hashes, changing sources, changed audio,
incomplete evidence, or any unknown ASR request. A RuntimeError swallowed by
production context recovery still invalidates the run via a sticky miss guard.

Measured: production speech.align, local CTC, word guidance, non-model DSP,
onset/end/letter refinement and final payload creation.
Excluded: imports, file decoding, ASR/MMS, model-assisted singing-mask generation,
trace wrappers, equality checks, hashes, JSON serialization and file writes.
Decoded waveforms, scores, independent ASR evidence and singing mask are reused
from the SAME baseline-v4-fresh recording for both versions. Pure acoustic
features other than the cached singing mask still run through production code.
This is NOT full-song/pipeline time, and does not measure inference speed.

Every validation, warmup and measured output must equal the exact payload.json
from the corresponding production trace. All measured values are retained.
CPU process time and monotonic wall time are both recorded. The script sets
OMP/MKL/OPENBLAS and Torch intra/inter-op to one thread in each fresh process.

Use four separate runs, in this order: baseline A1, final B1, final B2, baseline A2.
Do not combine different source hashes, input hashes, affinity or environments.
Compare medians of all 18 individual measured values per version/case (9x2),
not an average of two batch medians. Retain any outlier and report both batches.

At preparation time, the artist manifest selects 23s, 32s and 33s excerpts.
No independent word timing labels or model accuracy claims are supplied by this
benchmark. Local CTC windows and feature-call counts are observed once outside
the timer, separately from timed repetitions. No reference timing hints allowed.

Expected per-case success conditions in output:
  exactReferenceOutputForEveryRun=true
  inputsUnchanged=true
  cacheMisses=[]
  modelCalls=0
Overall completed=true and sourceHashesBefore=sourceHashesAfter.

Any failure means no completed benchmark claim, even if prior cases produced
timings. The failure report retains the exception and traceback. Do not silently
turn an uncached ASR request into an empty result or run new inference.
