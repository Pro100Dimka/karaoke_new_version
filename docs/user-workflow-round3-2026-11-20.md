## Исправления

| Действие пользователя | Причина сбоя | Результат исправления |
| --- | --- | --- |
| Очистить кэш или временные файлы во время обработки | Ручная очистка вызывала storage напрямую и могла удалить входные или рабочие файлы активной задачи. Отменяемая задача и подготовка до регистрации job также оставались незащищёнными. | Очистка атомарно допускается через существующий `run_when_idle`. Пока задачи используют данные, возвращается `StorageInUse`, а интерфейс просит дождаться их завершения. После завершения можно повторить очистку. |
| Очистить каталог с файлом, занятым другим процессом | Ошибка удаления каталога подавлялась, после чего он учитывался как удалённый. Для отдельного файла возникал необработанный `PermissionError`. | Ручная операция сообщает `StorageUnavailable` и фактическое число полностью удалённых элементов, не выдавая отказ за успех. При запуске приложения очистка остаётся необязательной: занятые файлы пропускаются. |
| Открыть сведения о хранилище, пока обработка удаляет временный файл | Файл мог исчезнуть между перечислением каталога и чтением размера, обрывая весь снимок с `FileNotFoundError`. | Подсчёт пропускает недоступный элемент и возвращает размеры остальных файлов. Дополнительных проходов по диску и обхода ссылок на каталоги нет. |
| Ввести API-ключ и получить ошибку сохранения | Черновик удалялся при отправке, а секрет намеренно отсутствовал в query snapshot; при отказе введённое значение исчезало из поля. | Отклонённое значение остаётся только в локальном состоянии открытого поля. Его можно исправить и сохранить повторно. Более поздний ввод или очистка не затираются запоздавшей ошибкой. В JSON настроек, query snapshot и уведомления сохранённый черновик не попадает. |
| Добавить несколько песен, среди которых есть дубль, отсутствующий или неподдерживаемый файл | Итоговое сообщение перечисляло только имена; причины отказа отбрасывались. При одиночном добавлении терялись незнакомые структурированные ошибки backend. | В общем сообщении у каждого отклонённого файла есть причина. Остальные файлы продолжают добавляться, временные элементы списка убираются. Незнакомая структурированная причина backend сохраняется и при одиночном добавлении. |

Сообщение о занятых данных добавлено на русском, украинском и английском. Ошибки очистки показывают локализованный текст без внутренних путей из ответа backend. Песни, записи и модели не входят в цели очистки; их сохранность проверяется в новых сценариях.
