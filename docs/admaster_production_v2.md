# AD Master v2: структура песни и обработка оригинала

Один анализ строит карту исполненной записи после всех исходных сдвигов, изменений темпа и тональности. Эта же карта используется для тембра, уровня и пространства. Пустое дополнение при сдвиге референса обозначается как неизвестный участок, а не как музыкальная пауза.

## Порядок обработки

Монтаж и коррекция нот предшествуют эффектам пространства. После вычитающей эквализации идут быстрый и плавный компрессоры, де-эссер, общая и локальная красящая эквализация, затем сатурация. Баланс измеряется уже после этих изменений тембра. Отдельные посылы добавляются к сухому вокалу один раз. Общие компрессор и лимитер работают после суммирования с минусом.

## Что описывает карта

Участки определяются по устойчивому изменению аранжировки и обработки референсного вокала. Возможные повторы объединяются по признакам; названия «куплет» и «припев» без достаточных данных не выдумываются. Анализ не зависит от обязательного фиксированного BPM. Громкие отдельные удары, короткие паузы и смена отдельных нот не должны создавать новую часть.

Общая калибровка уровня определяется один раз для исполненной записи. При достаточном сигнале сравниваются несколько частотных полос: избыток баса не должен автоматически приглушать всю дорожку вместе со словами. При недостатке согласованных данных используется общий уровень. По участкам затем меняется ограниченная поправка к этой калибровке; небольшие изменения внутри участка следуют собственным фразам исполнителя. Поправка на разборчивость не вычисляется заново для каждого участка, поэтому смена яркости оригинального певца не превращается в дополнительный скачок громкости.

Пространство измеряется локально, а посылы сохраняют непрерывные хвосты на границах. Низкая уверенность в конкретном эффекте отдельно отражается в диагностике.

Короткий согласованный стереоповтор проверяется по форме волны на независимых фрагментах и в нескольких частотных полосах. При подтверждении создаётся отдельная задержанная копия голоса исполнителя, а общий диффузный посыл исключается из этого участка. Отдельная нота, вибрато, противофаза и простое положение в стереопанораме не служат доказательством эха. Для чистого тонального пения дополнительно сравниваются ошибки предсказания нескольких конкурирующих задержек на одних и тех же проверочных отсчётах. Требуется преимущество выбранной задержки в обеих проверочных частях; неоднозначные периодические ноты сохраняют защитный отказ. Это ограниченная проверка неоднозначности, а не восстановление любой исходной цепочки эффектов. Уже имеющийся согласованный повтор сохраняется: повторное применение к обработанному входу могло бы создать лишнее эхо. Неполное совпадение с референсом отражается в отчёте. Диагностическое поле `targetCopyApplied` сообщает, добавлен ли рассчитанный посыл. Оно не оценивает совпадение всей обработки или художественное качество.

При оценке имеющейся реверберации исключается только доказанная мгновенная когерентная панорама. Сухая дорожка сохраняется без изменения: сдвиг голоса влево или вправо сам по себе не отменяет нужный пространственный посыл.

## Как проверяется результат

Регрессионные сценарии проверяют изменение тембра при одинаковой энергии, тихие фразы, отсутствие референса, изменяющиеся комнаты, сохранение эффекта в моно, непрерывность хвостов, неподвижный dry-путь, отсутствие повторного эффекта на уже обработанной записи, длительность, исходные файлы и выходной true peak. Независимые реальные примеры dry/wet использованы только для локальной проверки и не распространяются с приложением.

Отдельно проверялась исследовательская метрика AFx-Rep из [ST-ITO](https://github.com/csteinmetz1/st-ito). На другом певце она иногда предпочитала лишнюю реверберацию. Поэтому эта метрика не управляет автоматически силой эффектов и не является критерием художественного качества. Примеры dry/wet взяты со [страницы DiffVox](https://iamycy.github.io/diffvox-demo/).

Дополнительная локальная модельная проверка описана в [admaster_perceptual_validation.md](admaster_perceptual_validation.md). Она сравнивает заранее выбранные окна при одинаковой громкости и сохраняет результаты каждого окна вместе с хешами входов.

Численные проверки подтверждают конкретные свойства сигнала. Они не заменяют прослушивание и не доказывают художественную идеальность для любой записи.
