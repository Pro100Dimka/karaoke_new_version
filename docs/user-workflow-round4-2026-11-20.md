## Исправления

| Действие пользователя | Причина сбоя | Результат исправления |
| --- | --- | --- |
| Перетащить ноту или изменить её длину, затем отменить жест через Escape | PianoRoll синхронно отправлял отменённый preview и завершение жеста. React state ещё не обновился, поэтому завершение сохраняло старый preview. При изменении длины нулевой сдвиг дополнительно округлял исходную границу по сетке. | Ref предпросмотра обновляется синхронно; отменённое изменение длины возвращает точный исходный документ без округления. Escape и pointer cancellation восстанавливают исходные ноты, не создавая изменение в истории. Обычное завершение остаётся одним шагом Undo/Redo. |
| Переименовать запись и получить отказ сохранения | Форма очищала черновик и закрывала поле до завершения PATCH; обработчик сообщал об ошибке уже после потери введённого имени. | Форма закрывается только при успешном ответе. При отказе имя остаётся для исправления или повторной попытки. Пока запрос идёт, повторная отправка блокируется. Поздний ответ после закрытия и повторного открытия не стирает новый черновик. |
| Удалить запись или песню, когда физическое удаление её файлов временно запрещено | Метаданные уже удалялись из базы, но ошибка последующей уборки превращала успешное логическое удаление в ошибку API. Сохранённая операция восстановления могла снова вызвать эту ошибку и прервать следующий запуск backend. | Ошибка уборки после commit журналируется, а запись о незавершённой уборке сохраняется. Следующий запуск продолжает работу и повторяет уборку; после освобождения файлов остатки удаляются. Если commit не состоялся, исходные данные по-прежнему восстанавливаются. Ошибки восстановления ещё существующих данных не подавляются. |
| Скопировать или экспортировать диагностику при недоступном backend | Необязательное чтение списка задач отклоняло всю операцию, хотя сведения о других подсистемах уже были доступны. | Отчёт сохраняет доступные сведения, а список ошибок обработки помечается как `unavailable`. Настоящие ошибки записи файла или буфера обмена по-прежнему показываются; отмена диалога сохранения не выдаётся за успех. |
| Сохранить настройки песни с недоступным или неподходящим медиафайлом | Backend передаёт структурированный `AppError`, но форма преобразовывала объект через `String(error)`, показывая `[object Object]`. | Известный код получает локализованное объяснение, незнакомый сохраняет текст причины backend. Окно и введённые значения остаются для повторной попытки. |

Отложенная уборка не означает, что занятое место освобождается немедленно: заблокированные остатки удаляются при следующем успешном восстановлении. Изменения ограничены уже подтверждённым удалением песен и записей; восстановление импорта и публикации проектов не менялось.
