# A&D Voice 1.1.50

- Объединены код комнаты, задержка и мониторинг в одном компактном блоке. Плейлисты открываются через иконку в его шапке, обложка песни убрана.
- Публикация новой обработанной песни в комнате больше не ожидает завершения посторонней передачи проекта.
- Добавлены передача отдельных голосовых дорожек участников и их независимая обработка в Studio Master. Учитываются временные метки записи, разные частоты дискретизации, паузы и повторные подключения.
- Уточнена привязка начала записи к фактической позиции песни. Studio Master сохраняет участки записи за пределами доступной эталонной дорожки и остаётся доступным при неудачной оценке высоты голоса.
- Экспорт голоса защищён от одновременного перемещения исходника при архивировании записи.
- Включены улучшения отзывчивости микшера, редактора, просмотра записей и обновлений состояния комнаты. Закрытие предпросмотра отменяет ненужное построение звуковой волны.

Живая проверка комнат с 3–4 участниками ещё не завершена. Стабильная минимальная задержка, отсутствие периодических пропаданий звука и случайных искажений Windows-аудио пока не подтверждены. Этот выпуск не означает завершения проверки всех комнатных сценариев.

Перед публикацией установщик проходит автоматические проверки среды выполнения, новой установки, восстановления файлов и сохранения данных пользователя. Эти проверки не подтверждают качество живого звука.

Установщик `AD-Voice-Setup.exe` публикуется без цифровой подписи.
